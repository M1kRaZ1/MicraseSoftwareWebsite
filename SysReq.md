# Micrase's Assault — minimum system requirements

## Linux

- **Operating system:** A modern 64-bit Linux distribution.
- **Processor:** A 64-bit x86 processor that supports x86-64-v2. Not every 64-bit processor meets this requirement.
- **Graphics:** A graphics card or chip that supports OpenGL 2.0.

## macOS

- **Operating system:** macOS 12 Monterey or later.
- **Processor:** An Intel processor or an Apple M-series chip.
- **Graphics:** A graphics card or chip that supports OpenGL 2.0.

## Windows

Windows support is planned. These are the current minimum requirements:

- **Operating system:** Windows 7 or later.
- **Processor:** A 64-bit x86 processor that supports x86-64-v2. Not every 64-bit processor meets this requirement.
- **Graphics:** A graphics card or chip that supports OpenGL 2.0.

## Android

The game is not currently available for Android, and system requirements have not been published.
